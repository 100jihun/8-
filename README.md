# 8장  상속

상속의 Class간의 관계로 객채 사이의 관계는 아니다. (class 다이어그램에서 상속은 머리가 비어있는 화살표로 나타냄) 
부모 클래스에서 자식 클래스로 상속이 이루어지며 부모클래스는 자식 클래스보다 더 보편적이다. (자식 클래스가 더 많은 특징을 가진다.)
이미 만들어진 함수를 재사용할 수 있어서 편리하다. 기존에는 클래스 간의 관계가 없는데 상속을 통해 만들어진 부모, 자식이라는 계층으로 클래스를 구분할 수 있게 된다. 
자식 클래스에서 호출할 수 있는 부모 클래스의 멤버는 Public에 한하여 이루어진다. **Private 멤버도 자식 클래스로 상속되지만 접근 지정 범위는 Public이다.** ("금고에 넣어서 준 상속")

상속에서 객체 포인터 사용
**업 캐스팅** (up-casting) : 자식 클래 스포인터를 부모 클래스 포인터에 넣어도 자동으로 형 변환이 이루어진다.
  **객체 포인터의 제약** : 컴파일러는 포인터의 타입을 보고 작동하기 때문에 부모 클래스 포인터는 업 캐스팅이 이루어진다 하더라도 자식 클래스 멤버에 접근 할때 컴파일 오류가 발생한다.
**다운 캐스팅** (down-casting) : 명시적으로 지정해줘야 함. 자식 포인터 = (자식 클래스 타입*)부모 포인터 

protected 멤버 : 자식 클래스에서 부모 클래스의 멤버에 접근할 때만 허용하는 멤버.

생성자와 소멸자 : 자식 클래스의 생성자가 호출되면 그 자식 클래스의 코드를 보류하고 부모 생성자를 먼저 호출한다. 부모 생성자가 중복 선언 되어있다면 컴파일러는 기본 생성자를 우선한다.
          부모 생성자가 매개변수를 가지는 생성자 밖에 없으면 컴파일러는 기본 생성자를 찾지 못해 컴파일 오류가 발생. 자식 생성자에 ": 부모 생성자(원하는 호출의 매개변수)"로 지정할 수 있다.
          사실 자식 생성자의 선언에서 생략된 부분으로  ": 부모 생성자()"를 포함하고 있기 때문에 자식 클래스의 코드를 보류하고 부모 생성자를 먼저 호출하는 것처럼 보인다.

상속 지정 : 상속할 부분을 지정하는 것, Public(부모 클래스를 따름), Private(다른 멤버를 Private로), Prtected(Public을 Prtected로)
